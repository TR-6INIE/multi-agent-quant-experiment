## 三、回撤与交易

- **最大回撤 -16.68%（引擎报告值）**：按逐日收盘权益可精确复算为**1/12收盘1,073,905 → 1/26收盘894,758，-16.68%**，与日频口径完全一致。该回撤发生在1月持仓崩塌与再建仓的过程中，**远超方案自设的-8.0%停止线，且劣于上一轮（-12.01%）**——本轮核心改进在回撤维度上不但未达标，反而恶化。
- **机制开关节奏（共4轮建仓、4轮清仓，期末空仓）**：
  1. **期初承接持仓**（2025Q4遗留5只）→ 1/9、1/12机制内大幅换仓 → **1/16清仓**（breadth 0.7165当日仍高于0.50！）。**注意：1/16清仓时breadth=0.7165，远高于绝对阈值0.50，此次清仓只能由新增的 `breadth < breadth_ma - 0.05` 分支触发**（1/15 breadth 0.7494 → 1/16 0.7165，单日急跌且跌破均线减0.05）。这正是新机制"提前离场"的设计行为，但实际效果是**在宽度仍处高位时离场**，随后1/19–1/23 breadth回升至0.63–0.71，策略被迫于1/26再建仓——**缓冲带未能过滤1月中旬的宽度噪声**。
  2. **1/26建仓**（0.7430）→ **1/28清仓**（0.6013，同样高于0.50，由均线缓冲分支触发）。**持仓仅2个交易日**，权益从894,758到904,116基本持平，但支付了约45万元双边成交的佣金。这是本轮最典型的缓冲分支快速进出。
  3. **4/15建仓**（0.5899，紧贴0.58进场线）→ **4/27清仓**（0.5228，高于0.50，缓冲分支触发）。持有8个交易日，获利约+14.7万，清仓后4/30 breadth回升至0.5747。
  4. **5/7建仓**（0.6266）→ **5/15清仓**（0.3937，绝对阈值0.50触发）。持有6个交易日，获利约+7.4万。这是全区间唯一一次由绝对阈值触发的清仓。
- **缓冲分支主导清仓（数据结论）**：4次清仓中**3次由新增的均线缓冲分支触发（1/16、1/28、4/27），仅1次由0.50绝对阈值触发（5/15）**。缓冲分支确实比旧规则"更早"，但更早的时点发生在宽度0.52–0.72的相对高位，属于"高位离场"而非"阴跌止损"——机制行为与方案设计意图（针对10月式缓慢阴跌提前止损）**出现系统性偏差**。
- **锯齿检验**：清仓→再建仓间隔：1/16→1/26（6个交易日，不构成5日内）、**1/28→4/15（约52个交易日）**、**4/27→5/7（5个交易日，构成1次5日内再建仓）**。锯齿共**1次**，未突破方案"5日内清仓再建超过2次"的停止条件。
- **长期空仓**：2/2–4/14约48个交易日、5/18–6/30约31个交易日权益完全冻结。4/27清仓后breadth于4/30回升至0.5747、5/6至0.5481，距离进场阈值0.58一步之遥，直到5/7（0.6266）才再建仓，**错过约6个交易日的宽度修复段**。
- **佣金规模**：trades.csv逐笔求和约 **3,291元**，约占净利润1.3%、期初资产0.38%，摩擦成本可控。
- **执行异常**：**score空字段瑕疵本轮已修复**。全部47笔成交（含1/16、1/28、4/27、5/15的全仓SELL）均有有效score，审核问题A-001的修复在落盘数据中得到验证。state.csv全程selected=actual，无执行偏差。
- **换手率精确值无法计算**（无标准化口径）；47笔成交、粗估单边成交额约200万元量级（约2.3倍本金）。

## 七、可能原因（数据结论 vs 推测）

**数据可直接支持的结论**：
1. 3/4的清仓由缓冲分支在breadth 0.52–0.72触发，"高位离场"模式本轮系统性出现，与上轮"无高位离场"形成镜像；
2. 1/28清仓前持仓仅2个交易日，为四轮以来最短持仓窗口；
3. 最大回撤-16.68%可由日频收盘权益精确复算（1/12→1/26），口径本轮无歧义；
4. 75%的交易日空仓，覆盖基准大涨区间，负超额与长期缺席高度重叠；
5. score空字段瑕疵修复生效；收益高度集中于4月中与5月上两个窗口。

**推测（现有数据无法证明）**：
1. 若沿用纯0.50阈值，1/16与1/28两次清仓均不会发生，策略可能持有穿越1月下旬回撤并捕获2月后的行情——**缓冲分支可能是负超额与更深回撤的共同来源**，但无对照回测无法量化；
2. 0.05的绝对缓冲在breadth高位（0.6–0.8）时对应的相对波动占比过低，等效于无缓冲；方案文献依据（Zakamulin缓冲带理论）针对的是价格均线，直接外推至宽度指标可能不成立；
3. 1月+20万浮盈回吐提示持仓期内无利润保护机制，但引入止盈是否净改善无法从现有数据推断。

## 八、不可证明事项与偏差声明

- **股票池与申万一级行业为固定当前快照，幸存者偏差与分类前视偏差仍然存在**，本结果不能解释为完全无偏的历史检验。
- 无纯0.50阈值旧规则在2026H1区间的对照回测，本轮改动的增量贡献**无法量化**——已连续四轮缺失关键对照。
- 无基准逐日序列、无风险利率，Sharpe/Calmar/信息比率**无法计算**；空仓期基准涨幅无法逐段核算。
- 无逐票盈亏分解；无清仓触发分支的显式日志（缓冲分支 vs 绝对阈值的归因系本报告依据breadth数值推断，虽1/16等记录的breadth>0.50使归因基本确定，但仍建议引擎侧显式落盘触发原因）。
- 年化收益基于116天外推，不具统计稳健性；滑点为0、固定09:35成交，实际冲击成本未检验。
- 半年样本，收益由两个合计约15个交易日的窗口决定，无法区分选股能力、择时能力与行情运气。

## 九、下一轮可验证建议

1. **响应停止条件（最高优先级，必须执行）**：MDD -16.68%连续第二轮突破-8.0%停止线，且缓冲均线分支被证明在高位宽度波动中反向恶化回撤。按方案约定应**回退或实质重构出场机制**。建议优先候选：(a) 直接回退至纯0.50绝对阈值（第四轮版本）；(b) 将缓冲分支限定为**低位语境**（如仅在breadth < 0.55时才启用均线缓冲判断），区分"高位回落"与"低位阴跌"。
2. **基线对照回测（连续第四轮提出，升级为阻塞项）**：在同一冻结引擎上对2026H1区间跑"纯0.50阈值"对照版本，量化缓冲分支对1月两次清仓、全区间收益与MDD的净影响。没有该对照，出场机制的任何参数调整都不具备证据基础。
3. **进场机制的机会成本审计（升级为高优先级）**：本轮75%空仓发生在基准+57%的环境中，2/2–4/14宽度从0.21修复至0.45的整段均未进场。建议系统统计"breadth介于0.45–0.58且持续站上均线的天数"与对应基准涨幅，评估分级进场（如宽度0.50–0.58半仓）的可行性。
4. **持仓期利润保护机制研究**：1月+23%浮盈全额回吐、4月建仓当日浮亏，提示机制级清仓信号不足以保护窗口内利润。建议下一轮评估移动止盈或分批止盈的回测证据（作为独立候选，不与出场机制改动捆绑）。
5. **清仓触发原因显式落盘**：建议工程师在trades.csv或新增字段中记录触发清仓的具体分支（绝对阈值/均线缓冲/排名替换），消除归因推断环节。
6. **收益集中度审计常规化**：本轮两个窗口决定全区间结果的模式与上轮一致，建议固定输出"前N大盈利日贡献占比"，并追踪1月式"浮盈回吐"指标（窗口内最高权益与清仓权益之差）。
7. **缓冲带参数的自适应化研究（若保留缓冲思路）**：本轮证据表明固定0.05绝对缓冲在高位宽度区间失效；若未来重新引入缓冲，应基于宽度自身波动率（如过去20日breadth标准差的倍数）而非固定绝对值，并先在历史区间做参数敏感性扫描。

## 2. 上轮 WSUR 指标本轮复算（跨季追踪）

$$WSUR = \frac{\sum_t \mathbb{1}\{target\_count_t > 0 \land breadth_t \geq 0.50\}}{\sum_t \mathbb{1}\{breadth_t \geq 0.50\}}$$

据 equity.csv 复算：breadth ≥ 0.50 的交易日共 **42 天**（1 月 20 天、02-02、03-02/03-03 共 2 天、04-16 至 04-30 共 11 天、05-06 至 05-15 共 8 天）；其中持仓日 **41 天**（仅 05-15 在 breadth=0.5038≥0.50 时清仓离场）。**WSUR = 41/42 ≈ 0.976**（上季 26/27 ≈ 0.963）。恒等式检查通过。

**解释（区分结论与推测）**：WSUR 连续两季 ≥0.96，"该在场时在场"维度无踏空是数据结论；但 05-15 这个唯一缺口恰好是 breadth_3d 仍在 0.50 上方时的离场，WSUR 不惩罚"提前离场后宽度下行"的择时收益，也不度量其机会成本——该指标只覆盖择时问题的一半，需与超额和回撤联合解读。

## 3. 新指标提案：碎单摩擦占比（Crumb Friction Share, CFS）

**动机**：本轮方案以碎单为改进目标却自触停止线，但"碎单占比 >40%"只数笔数、不数钱。需要一个同时度量笔数与费用相对负担的可复算指标，跨季追踪摩擦成本。所需字段（trades.csv 的 `quantity`、`commission`）**已确认可得**，公式可直接运行。

**公式定义**：

$$CFS_{count} = \frac{\#\{i: qty_i < 1000\}}{N_{trades}}, \qquad CFS_{comm} = \frac{\sum_{i: qty_i<1000} commission_i}{\sum_{i=1}^{N} commission_i}$$

- 1000 股阈值与方案停止条件口径一致；两者联合解读：若 $CFS_{count}$ 高而 $CFS_{comm}$ 低，碎单名义金额小、费用负担可控；若双高，则摩擦问题实质恶化。

**本轮复算（据 trades.csv，约值）**：$CFS_{count}$ ≈ 44/93 ≈ **0.473**。$CFS_{comm}$：44 笔碎单佣金多数为 5.00 元最低档（少量 6–13 元），合计约 **250 元**；全部 93 笔佣金合计约 **4,700 元**（大额单笔 60–185 元为主），$CFS_{comm}$ ≈ **0.05**。恒等式检查：分子 ≤ 分母成立，0 ≤ CFS ≤ 1 成立。

**解读（数据结论）**：碎单笔数占比近半、已触停止线，但佣金占比仅约 5%——**碎单的真实费用负担有限，方案以"节约佣金"为主要论证的支持度不足**；碎单的主要代价更可能体现在信号噪音与"两日游"式无效换仓，而非直接佣金。这一区分只能靠 CFS 双口径揭示，单看笔数会高估问题、单看金额会低估信号质量问题。

## 4. 可验证的下一轮假设

# 代码审核报告

## 一、基本工作：增量改动与代码安全审核

### 1. 相对基线的实际改动识别

通过对候选代码与基线代码进行差异比对，本轮真实改动仅集中在市场广度择时入场逻辑上，具体如下：

- **新增变量 `breadth_1d`**：在平滑广度计算完成后，提取最近单日（`signal_i`）的原始广度值 `breadths[0]`。
- **修改入场门槛判断逻辑**：基线中的入场条件为 `elif breadth >= ENTRY_BREADTH:`（仅依赖3日平滑广度）；候选代码修改为 `elif breadth >= EXIT_BREADTH and breadth_1d >= ENTRY_BREADTH:`。
- **注释更新**：增加了关于“使用最新单日广度作为入场确认”的说明。

除上述择时逻辑改动外，选股评分、行业约束、退出逻辑及组合构建等部分均与基线完全一致。

### 2. 静态审核与安全性检查

**审核结论**：本轮改动无阻断或严重问题，代码实现安全、合规。

### 3. 增量类型判定

**增量类型：实质机制改进**

候选代码将入场条件从单一的“3日平滑广度 ≥ 0.58”升级为“3日平滑广度 ≥ 0.50 且 最新单日广度 ≥ 0.58”。
这并非简单的参数阈值调整，而是引入了**双广度确认机制**：
- **退出与持仓基准**：继续使用平滑广度（`EXIT_BREADTH = 0.50`），过滤噪音，避免单日闪崩导致的误退出。
- **入场确认基准**：要求单日广度突破严格阈值（`ENTRY_BREADTH = 0.58`），确保市场短期动能真实恢复后再新增仓位。

该改动实现了平滑滤波与实时响应的有效分离，属于择时机制层面的实质改善。

## 二、绩效工作：创新审计与过拟合验证

### 1. 实质创新与机制改善评估

候选代码的改动在择时机制上形成了实质创新。基线策略的平滑广度虽然能减少假信号，但在市场由弱转强的拐点处存在明显滞后。候选代码通过分离平滑广度与单日广度的职责，构建了非对称的择时框架：
- **离场宽容**：只要平滑广度未跌破0.50即维持持仓，容忍单日剧烈震荡。
- **进场严苛**：需要平滑广度脱离极弱区（≥0.50），且单日市场强势确认（≥0.58），有效防止在阴跌反弹中过早进场。

这种“双轨广度”确认机制在不改变选股与组合构建的前提下，显著优化了择时逻辑的鲁棒性。

### 2. 与参考策略的新增重合检查

经比对提供的机密参考策略：
- 基线及候选代码的整体架构（动量分位数评分、行业中性约束、广度滞后择时）与 `broad_industry_neutral_momentum_v2.py` 高度同源，但本轮改动**未直接照搬**任何参考策略。
- 参考策略 `v3_2` 中虽然存在复杂的盘中广度确认与多档敞口调整，但候选代码的改动仅是在日级别引入单日确认，未涉及盘中机制或动态敞口。
- 候选代码的入场条件设计具有独立性，不构成对参考策略的抄袭。

### 3. 过拟合风险与验证办法

尽管改动具有实质机制改善，但“平滑广度脱离底限 + 单日广度突破”的复合条件存在一定的历史拟合风险。验证办法如下：
1. **阈值敏感性测试**：将 `ENTRY_BREADTH`（0.58）在 [0.55, 0.60] 范围内以0.01步长扫描，若收益对0.58极度敏感而对邻近值大幅衰减，则判定为过拟合。
2. **机制消融实验**：在评价区间内分别运行“仅平滑广度入场”与“双广度确认入场”的对照回测，观察新增的单日广度条件是否在多数子区间内一致性地降低了最大回撤或提升了夏普比率。
3. **事件样本分析**：统计历史上满足“平滑广度≥0.50但单日广度<0.58”的交易日及其后5-10日的市场走势，验证该条件是否有效过滤了虚假反弹。

### 4. 不确定性

候选代码在 `breadth_1d >= ENTRY_BREADTH` 的判断中，复用了基线 `ENTRY_BREADTH` 的常量值（0.58）。虽然逻辑上合理，但单日广度的波动特性与3日平滑广度不同，直接共用同一阈值可能并非最优。建议在后续验证中关注该阈值的独立最优区间。

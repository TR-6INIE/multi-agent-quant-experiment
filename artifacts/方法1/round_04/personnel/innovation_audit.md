# 基本工作：对抗性审计

## 一、相对基线的实际改动

通过逐行比对，候选代码相对基线的唯一实质改动位于 `decide` 方法的择时分枝逻辑：

**基线逻辑：**
```python
elif breadth >= EXIT_BREADTH and breadth_1d >= ENTRY_BREADTH:
```

**候选逻辑：**
```python
elif breadth >= EXIT_BREADTH and breadth_1d >= breadth:
```

其余所有代码（包括 `breadth_1d` 的提取方式、3日平滑逻辑、打分排序、组合构建、行业约束）均与基线逐字符一致。

**改动实质**：将新建仓门槛从“单日广度超过绝对阈值 0.58”替换为“单日广度超过近3日平滑广度”。
- 常量 `ENTRY_BREADTH = 0.58` 虽然保留在文件中，但在候选代码中已变成死参数，不再参与任何路径。
- 新建仓门槛变为一个**动态相对条件**。由于 `breadth` 是 `breadths[0]`（当日）、`breadths[1]`（前日）和 `breadths[2]`（大前日）三者的均值，而 `breadth_1d = breadths[0]`，因此 `breadth_1d >= breadth` 等价于 `breadths[0] >= (breadths[0] + breadths[1] + breadths[2]) / 3`。化简后，该条件等价于 `2 * breadths[0] >= breadths[1] + breadths[2]`。

## 二、增量类型判定

**类型：实质机制改进（动态门槛机制）**

该改动不仅是参数微调，而是改变了机制类型：
1. 从绝对阈值变为相对边际确认，门槛高度随市场状态浮动。
2. 在强趋势上涨期（平滑值被前期低位拉低），新建仓门槛实质降低，可能在 `breadth` 处于 0.51-0.57 区间时更早建仓。
3. 在市场高位回调期（当日值低于前两日），新建仓门槛实质收紧。

## 三、问题分级审核

### 阻断问题
无。代码不存在数据链路断裂、静默零交易风险或时序违规。`breadths` 列表构造逻辑未变，`breadth_1d = breadths[0]` 的提取方式未变，字段语义明确。

### 严重问题
无。语法、接口、持仓约束均正常。

### 一般问题
1. **参数遗留与死代码**：`ENTRY_BREADTH = 0.58` 成为死参数。虽不影响运行，但易造成维护歧义，建议删除或注释说明。
2. **常态条件易被忽视**：候选逻辑的 `elif` 分支隐含要求 `breadth_1d >= PANIC_BREADTH`（0.40）且 `breadth_1d < breadth` 时进入仅持仓状态。由于 `breadth >= 0.50` 时，若 `breadth_1d < breadth`，则 `breadth_1d` 仍有可能高于 0.40，此分支行为正常。但需注意，若市场处于 3 日连续下行（breadth_1d 远低于前两日），即使平滑广度仍维持在 0.55，策略也不会补充新仓，这属于动态收紧的正常机制表现。

### 建议事项
1. **敏感性验证**：新增逻辑的建仓行为对市场的“上行斜率”高度敏感。建议在实际回测中观察 2025 年 Q4 期间，该条件触发新建仓的频率，以及是否存在“门槛过低导致过早建仓”的风险。
2. **过拟合风险评估**：由于条件 `2 * breadths[0] >= breadths[1] + breadths[2]` 本质是“广度短期均值高于中期均值”，这是一种“广度动量”确认。但在市场剧烈波动时（如 V 型反转），该条件可能频繁切换，导致组合在“持仓”和“新建仓”间反复跳动。

# 绩效工作：系统性风险与原创性评估

## 一、系统性风险发现

1. **广度动量与价格动量的正反馈风险**：候选代码用“广度动量”（breadth_1d >= breadth）来确认“价格动量”策略的新建仓。在普涨初期，两者同向共振，有利于快速建仓；但在市场分化期（指数上涨但广度下降），该条件会自动锁死新建仓，这虽然是一种风控，但也可能导致策略在“缩量牛”阶段完全踏空后续行情。
2. **极端早盘广度缺失路径**：若 `t < 59` 导致循环提前 break，`breadths` 可能只有 1 或 2 个元素，`breadth` 的平滑意义丧失。此时 `breadth_1d >= breadth` 退化为 `breadths[0] >= breadths[0]`（恒为 True）或 `breadths[0] >= (breadths[0]+breadths[1])/2`（仅需当日不比昨日低）。这在策略冷启动期间会显著降低建仓门槛。

## 二、原创性判断

**结论：具备原创性，非直接照搬。**

**证据**：
1. **与机密参考策略对比**：
   - `broad_industry_neutral_momentum_v2.py` 使用绝对阈值 0.58 作为建仓门槛。
   - `broad_industry_neutral_momentum_v3_2_t1_width_scaling.py` 使用 0.50/0.54/0.58 三档绝对阈值结合日内反转机制。
   - `simple_ma_cross_industry_v1.py` 基于 MA 交叉，与广度无关。
   - 候选代码的“单日广度突破 3 日平滑广度”这一动态相对确认逻辑，在所有提供的参考策略中均未出现。

2. **不因收益目标降低标准**：
   - 尽管该改动从理论上有助于提高趋势跟随的时效性，但由于其本质是引入了新的二阶导数条件（广度动量），这在复杂度上增加了模型的自由度。如果不加以约束，这种“适应性门槛”极易成为拟合历史波动的工具。
   - 审核不因其可能提升收益而放松对其过拟合潜力的警惕。该改动通过审计的的前提是其逻辑简洁且不具备隐藏的参数自由度（仅移除了 0.58 的硬编码，未引入新参数）。

**审核结论：通过。**

候选代码的增量改动真实存在，从绝对阈值转变为动态相对门槛，属于实质机制改进。逻辑清晰，未发现阻断或严重问题，未发现抄袭参考策略。建议后续关注 Q4 行情中该动态门槛的触发频率与稳定性。

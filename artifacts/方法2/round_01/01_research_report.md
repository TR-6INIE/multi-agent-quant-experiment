# 策略研究员增量改进方案

## 基本工作
本轮研究针对基线策略 `broad_industry_neutral_momentum_local_v1` 进行机制诊断与增量改进设计。通过检索决策日（2024-12-31）前的公开文献，识别基线在A股市场环境下的潜在风险，并对比多个候选改进方案，最终选定一项核心机制改进交付工程师实施。

## 基线策略拆解
基线策略是一个基于多周期动量和市场宽度的日频选股、5分钟频执行的量化策略：
1. **信号生成**：计算20日、40日、60日收益率，按0.40、0.35、0.25加权得到综合动量得分，并进行截面百分位排名。
2. **过滤条件**：上市及有效数据>=61天，收盘价>20日均线，6日平均成交额>=5000万。
3. **仓位控制（市场宽度 Breadth）**：计算全市场收盘价大于20日均线的股票比例。
   - `Breadth < 0.50`：清仓。
   - `Breadth >= 0.58`：满仓调仓，选取TOP 5，行业中性（每行业最多1只），带有2.0倍的保留缓冲。
   - `0.50 <= Breadth < 0.58`：仅保留现有持仓，不新开仓。

## 基线问题诊断
1. **纯动量因子的“高波动陷阱”**：基线直接使用多周期收益率作为动量信号。在A股市场，短期暴涨的股票往往伴随极高的波动率。纯收益率动量容易在行情末端选中这些“妖股”，随后在T+1制度下面临流动性枯竭或高位接盘，导致剧烈回撤。
2. **缺乏风险调整**：未考虑收益率背后的风险代价，导致高波动、低夏普的股票与低波动、高夏普的股票在排名中获得同等权重。

## 外部证据
- **Bruder et al. (2013) "Trend Filtering Methods for Momentum Strategies"**：指出动量策略中直接使用价格趋势容易受到噪声和极端波动的影响，引入风险调整（如波动率归一化）或更平滑的趋势过滤能显著提升夏普比率，降低尾部风险。
- **Husmann et al. (2019) "Sparsity and Stability for Minimum-Variance Portfolios"**：强调了在组合构建中考虑稳定性和风险调整的重要性，指出未经风险调整的收益信号容易受到估计误差和极端值的影响。
*证据局限*：上述文献多基于成熟市场或宏观资产，A股特有的T+1、涨跌停板及散户主导特征可能使波动率惩罚的边际效用与文献结论存在偏差，需通过实验验证。

## 候选增量改进比较
| 候选方案 | 机制描述 | 优点 | 缺点 | 结论 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 风险调整动量** | 将各周期收益率除以对应周期的日收益率标准差。 | 直接改善选股质量，降低高波动妖股权重，减少回撤；实现简单，计算量极小。 | 在极强单边疯牛市中可能错过最高弹性的标的。 | **选定** |
| **2. 平滑市场宽度** | 对 Breadth 指标进行5日移动平均。 | 减少仓位在阈值附近的频繁切换。 | 基线已有0.08的缓冲区间，平滑信号可能导致逃顶/抄底延迟，增加系统性风险暴露。 | 放弃 |
| **3. 换手率惩罚** | 在得分中给予已持仓股票固定加成。 | 降低交易成本。 | 基线已有 `KEEP_BUFFER=2.0` 的保留机制，进一步加成可能导致持仓僵化。 | 放弃 |

## 本轮唯一选定改进：风险调整动量（Volatility-Adjusted Momentum）
将基线中的纯收益率动量替换为“收益率/波动率”形式的风险调整动量。通过惩罚高波动股票，使策略更倾向于选择趋势稳健、夏普比率高的标的。

## 明确保留项
- 股票池过滤逻辑（历史天数、均线、成交额）。
- 市场宽度（Breadth）计算及仓位控制逻辑（EXIT/ENTRY 阈值，`_choose_desired` / `_choose_kept`）。
- 行业中性约束（`MAX_PER_INDUSTRY=1`）和持仓数量（`TOP_K=5`）。
- 多周期权重（0.40, 0.35, 0.25）及截面百分位排名逻辑。

## 精确修改规则
在 `Strategy.decide` 方法中，修改计算 `components` 的循环体。将原始收益率 `raw_ret` 除以对应周期的日收益率标准差 `vol`。处理 `vol` 为0或NaN的情况，避免除以0。

```python
# 修改前：
# raw = closes[signal_i] / old - 1.0

# 修改后：
raw_ret = closes[signal_i] / old - 1.0

# 计算过去 lookback 天的日收益率标准差
period_closes = closes[signal_i - lookback:signal_i + 1]
safe_closes = np.where(period_closes[:-1] > 0, period_closes[:-1], np.nan)
daily_rets = (period_closes[1:] - period_closes[:-1]) / safe_closes
vol = np.nanstd(daily_rets, axis=0)

# 风险调整
raw = raw_ret / np.where(vol > 1e-6, vol, np.nan)
```

## 资源增量清单
- **数据接口**：无新增，仅使用 `SafeStrategyContext.closes`。
- **计算资源**：新增日收益率和标准差的向量化计算。在 numpy 下耗时增加 < 10ms，完全满足5分钟频执行要求。
- **内存**：新增少量临时数组，峰值内存增加 < 5MB。

## 数据时点与防未来函数
- **数据时点**：所有计算严格使用 `signal_i = len(closes) - 1` 及之前的数据。
- **防未来函数**：波动率计算切片 `closes[signal_i - lookback:signal_i + 1]` 仅包含截至 `signal_i` 的历史收盘价；`daily_rets` 计算使用 `[:-1]` 和 `[1:]`，无前瞻偏差。

## 参数来源
- 周期参数 `20, 40, 60` 继承自基线。
- 波动率阈值 `1e-6` 为工程防除零常数，无业务含义。
- 无新增超参数。

## 可证伪假设
- **假设**：在A股市场，经过波动率调整的动量因子比纯动量因子具有更高的风险调整后收益，且能有效降低最大回撤。
- **证伪条件**：若评价区间内市场呈现极端的“高波动=高收益”特征（如微盘股疯牛），且波动率调整导致策略错过领涨龙头，使得实验组绝对收益和夏普比率均显著低于基线组，则假设被证伪。

## 失效与停止条件
- **失效场景**：市场长期处于极低波动率的阴跌状态，所有股票波动率趋近于0，导致风险调整后的得分失真（尽管有 `1e-6` 保护，但排名可能退化为随机）。
- **停止条件**：若实验组在评价区间内的最大回撤超过基线组，且年化收益率低于基线组，则说明该改进在当前市场环境下失效，下轮需回滚。

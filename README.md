# 多智能体组织制度与既有量化策略改进实验

本仓库公开一个五轮、多智能体量化策略研发实验的归档版本。实验以既有的行业中性宽基动量策略 `broad_momentum_strategy.py` 为统一起点，在模型、职位、技术任务和冻结回测环境尽量一致时，比较三种组织机制对连续策略改进结果的影响。

四个固定职位及模型为：Qwen（策略研究员）、DeepSeek（策略工程师）、GLM（代码审核员）、Kimi（数据分析师）。三个方法为：

- **方法1：完整人事制度组**——私有职级、履职标准、述职、管理员评分、随机社会分与晋升。
- **方法2：结构化反思组**——没有职级和晋升，每轮保留任务导向的私人复盘。
- **方法3：普通协作组**——只有常规职位分工，不加入人事制度或结构化复盘。

三组均从同一既有策略开始，每轮依据上一轮冻结策略提出有限改进。代码经审核后进入冻结本地回测；评价区间按季度从2025年第一季度推进至2026年上半年，资金和持仓跨轮延续。

## 主要结果

初始资金均为500,000元。五轮累计结果如下：

| 方法 | 最终资产（元） | 累计收益 | 五轮交易数 | 单轮最差回撤 |
|---|---:|---:|---:|---:|
| 方法1 | 1,720,000.48 | 244.00% | 409 | -14.88% |
| 方法2 | 1,023,890.35 | 104.78% | 617 | -24.48% |
| 方法3 | 1,114,636.42 | 122.93% | 291 | -16.68% |

方法1在这一归档实验中的最终资产最高，但这只是单次、固定模型职位匹配和固定市场路径下的观察结果，不能据此证明人事制度具有普遍因果优势。每轮完整聚合结果见 [`results/round_metrics.csv`](results/round_metrics.csv)。

## 版本边界

本仓库对应归档：`20260815_既有策略五轮完成_开放设计改造前`，其状态版本为 `schema 3`、策略模式为 `incremental_improvement`。它早于后来采用空白脚手架的开放式策略设计实验，两者不应串联比较。

仓库中的调度源码保留了兼容入口，权威历史记录是 `artifacts/` 中的冻结策略和精选输出以及 `results/` 中由归档结果机械汇总的指标。原始行情、财报、逐日净值和逐笔成交均未公开，因此无法仅凭本仓库精确复算这些数值。

## 重要限制

- 本仓库不包含股价、成交、财务、指数、行业成分、QMT DAT、缓存、逐日净值、逐笔成交或每日持仓状态。
- 股票池和申万一级行业使用固定当前快照，保留幸存者偏差与行业分类前视偏差。
- 模型与职位固定，样本只有三组各一次实验，缺少重复随机试验。
- 三组策略连续跨轮继承资金、持仓和前轮代码，轮间结果不是相互独立样本。
- 本实验不是投资建议，回测收益不代表未来表现。

## 快速开始

```powershell
python -m pip install -r requirements.txt
Copy-Item .\管理员\config\experiment.example.json .\管理员\config\experiment.json
Copy-Item .\管理员\config\models.example.json .\管理员\config\models.local.json
python -m unittest .\管理员\test_local_workflow.py
```

随后按照 [`REPRODUCE.md`](REPRODUCE.md) 准备自有数据并配置API环境变量。真实密钥只能放在环境变量或未跟踪的 `models.local.json` 中。
